# 🎨 · DrawGen

SillyTavern 第三方生图扩展。

## 1.7.0：与 Tavo 生图工坊 v1.18.x 对齐

- 首次安装自动播种内置站点档案（生图 13 个 + 提取 1 个，地址 / 模型 / 尺寸 / 画质随档案带好，**Key 为占位符 `sk-在此填入你的Key`，需自己填中转站密钥后才能生图**）；只播一次，已有站点的老用户不受影响，之后完全自己增删改。
- 生图设置新增「画质 quality」下拉（GPT 2.5 系 low/medium/high/xhigh/max，Grok low/medium/auto，留空不发送），选择随站点档案保存。
- 生图统一先走 `chat/completions`，失败自动退 `images/generations`；地址直指 images 接口时直连；站点只认 `response_format=url`（如 fate）被 400 拒时自动改发 url 重试一次。
- 尺寸里的全角 `×` 发送前自动归一化成半角 `x`，避免部分站点秒拒。
- 生图超时（默认 300 秒，可调）与「停止」按钮真正能掐断请求；超时 / 取消后不自动补发，以免重复扣费。
- 失败提示直接给 HTTP 状态码（429 / 402 / 401 等）和站点返回的原话，不再倒一大坨英文。
- 画风行新增 ⬆ / ⬇ 按钮：导出画风 JSON（只含画风，不含 API 与密钥）；导入兼容画风包与预设包——模板拆成前缀 / 后缀两段（构图脚手架进前缀、风格正文进后缀，分层生图时前缀占位符自动填当楼六层值），提取规则 / 系统提示 / 角色锚点按名字归并，旧五标签合同导入时机械升级为六标签。
- 楼层挂图仍用酒馆版自己的 `image###…###` 标记原位替换方式，与 Tavo 端的消息附件挂载互不相干；其余生图 / 提取逻辑两端通用。

## 1.6.34：简洁的手机图片预览

- 点开时先完整显示图片，按屏幕等比缩小，不再默认放大到 100%。小尺寸图片不会自动放大。
- 始终加载当前选中的原图；放大和缩小都保持原图长宽比例，不拉伸、不改图片数据或分辨率。
- 手机双指捏合放大、缩小；放大后可单指拖动查看。手势只影响预览图片，不缩放整个酒馆页面。
- 界面只保留图片和右上角的小关闭叉，不显示工具栏、比例、切换按钮或加减按钮，也不添加电脑滚轮缩放。
- 每次重新打开都恢复完整图片视图；保留 Esc/背景关闭、焦点恢复、历史图片选择和旧 WebView 弹窗兜底。

### 更新

通过 Git 安装的用户可在酒馆扩展管理里更新本插件，随后完整刷新页面，确认版本为 `1.6.34`。

手动安装：先备份插件目录中的 `index.js`、`style.css`、`manifest.json`，再用新版本的三个同名文件覆盖。不要创建重复的嵌套目录，无需重新生成已有图片。

此修复不更改聊天图片数据或生图 API 配置，也不会把低分辨率图片变成高分辨率图片。

### 开发与回归测试

Node.js 版本要求以 `package.json` 的 `engines` 为准：

```sh
npm ci
npm run check
npm test
```

运行时仍只需要 manifest 指定的 `index.js` 和 `style.css`；npm 依赖仅用于开发测试。

自动化测试覆盖图片打开、历史选择、默认适屏、等比缩放、双指中点、单指拖动、手势取消、缩放后关闭/重开、键盘焦点及清理；并验证没有增加滚轮缩放或额外按钮。触摸手势通过模拟 PointerEvent 检查。

另在真实浏览器的 390 × 844 窄屏视口检查初始完整显示、图片比例和小关闭叉。尚未在用户实际酒馆主题或手机触屏上实测。
