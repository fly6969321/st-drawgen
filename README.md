# 🎨 · DrawGen

SillyTavern 第三方生图扩展。

## 1.6.33：原图尺寸查看与小型关闭按钮

- 打开预览时默认以 **100% 原图固有尺寸**显示，不再强制缩小到屏幕宽度。这里的 100% 是浏览器的 CSS 像素尺寸，不是提高图片分辨率。
- 大图可以在手机上滑动、在电脑上滚动或按住鼠标拖动，查看屏幕以外的部分；打开时从图片中央开始。
- 顶部提供“适应屏幕 / 原图 100%”切换，同时显示当前比例与原图宽高。适屏模式保持比例，不放大小尺寸原图。
- 右上角改为 18px 的小叉，去掉原来的大圆圈，保留 36px 的点击区域。
- 打开预览期间锁定背景滚动；关闭后恢复。适配窗口大小变化，并防止拖动结束后误关弹窗。
- 保留 1.6.32 的标记图片、无标记楼层图片、历史翻页、Esc/背景关闭、键盘操作，以及旧 WebView 弹窗兜底。

### 更新

已通过 Git 安装的用户可在酒馆扩展管理里更新本插件，随后完整刷新页面，确认版本为 `1.6.33`。

手动安装：先备份插件目录中的 `index.js`、`style.css`、`manifest.json`，然后用修复包中的三个同名文件覆盖。不要创建重复的嵌套目录，也无需重新生成已有图片。

此修复不更改聊天图片数据或生图 API 配置，也不会把低分辨率图片变成高分辨率图片。

### 开发与回归测试

Node.js 版本要求以 `package.json` 的 `engines` 为准（本次验证使用 24.18.0）：

```sh
npm ci
npm run check
npm test
```

运行时仍只需要 manifest 指定的 `index.js` 和 `style.css`；npm 依赖仅用于开发测试。

自动化测试覆盖原有点击预览功能，以及原图尺寸、适屏切换、长宽比、窗口调整、鼠标拖动、触摸事件不拦截、焦点循环和关闭清理。另使用真实浏览器的本地模拟聊天页检查 390 × 844 窄屏下的原图尺寸、切换、拖动及关闭按钮样式。

尚未在用户实际酒馆主题或手机触摸环境中验证本次更新。
