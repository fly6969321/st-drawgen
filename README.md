# 🎨 生图工坊 · DrawGen

SillyTavern 第三方扩展 —— 独立生图插件。

```
AI 回复 → 副AI提取生图描述（整段 / 分层）→ 注入 image###…### 标记 → Grok / Gemini 生图 → 标记原位换成图片
```

楼层正文里每一个 `image###…###` 标记就是一张图，原地显示。

## 安装 / 更新

- 扩展面板 → Install extension → 填本仓库地址
- 已装过：扩展面板 → Manage extensions → 生图工坊 → Update → 刷新页面

## 入口

- **悬浮球 🎨**：拖动挪位置，单击开关面板
- **扩展抽屉**：Extensions 里的「🎨 生图工坊 DrawGen」折叠块，可打开面板、切主题、总开关、隐藏悬浮球

面板顶栏 🌞 / 🌙 切日版 / 夜版。

## 面板

- 顶部状态条常驻
- **两个页签卡片**：「🎨 生图」「📝 提取」，点哪个展开哪个
- 工作区（预览框 · 提取 / 注入 / 生图 / 停止 · 分层）在**提取页**里
- 生图和提取都能存**多个站点**随意切换：下拉旁边 ＋ 新建、✎ 改名、🗑 删除，每个站点各自记地址 / Key / 模型
- 模型点「拉取模型」拉回来在下拉里选，不用手敲；要手填点 ✎
- 提取页分两个独立分区：**🎨 画风**（管出图风格）和 **📝 提取规则**（管副AI怎么写描述），两者互不相干
- 画风、提取规则、角色锚点各自都能存**多套预设**，下拉随时切，＋ 新建、✎ 改名、🗑 删除

## 生图

- 正文里的 `image###描述###` 就是标记，一楼几个标记几张图，图显示在标记原来的位置
- 没出图的标记显示「生成图片」按钮，点一下单独生成
- 出图后是一条折叠条「📷 点击查看图片」，点它收起 / 展开；条右边 ↻ 重画这一张
- 重画不覆盖旧图：同一处的历史都留着（最多 20 张），折叠条上 ‹ 1/3 › 翻着看
- 图按左右滑的回复分开存，滑到别的回复不会串图
- 图片默认撑满楼层宽度，可在生图页改
- 楼层里的英文提示词文字默认收起，只在面板预览框里看
- 楼层操作栏 🖼 = 这一楼全部标记重新生图；🎨 = 按当前模板重新注入
- 只替换正文里的标记文字，状态栏等其它美化插件渲染的内容原样不动
- 主模型自己写了标记就不叫副AI，直接生图
- 图片存在楼层数据里，切聊天 / 刷新不丢；点图开灯箱
- 渠道：Gemini 走 `chat/completions` 多模态；Grok 走 `images/generations`。地址填到 `/v1`

## 提取

- 副AI读正文，输出英文描述，按模板拼成标记追加到楼尾。默认模板 `image###{Description}###`
- **分层提取**：还是一次请求，副AI按五个标签分节输出，插件拆成五框：镜头 📷 / 环境 🌆 / 氛围 🎞️ / 人物 🧍 / 动作 🤝
  - 锁住的层下次不重提，原样喂回副AI，要求其余层与它保持一致
  - 环境 / 氛围场景没换时副AI只回 `NO_CHANGE`，自动沿用上一楼
  - 每层 ↻ 只重摇这一层
  - 模板里可用 `{Camera} {Env} {Mood} {Chars} {Pose}` 单独放层；`{Description}` 拿没单独放的层

## 自动化

收到 AI 回复 → 延迟 → 自动提取 → 自动注入 → 自动生图，三步各自可关。

## 注意

- 自动生图会真实消耗额度，先「测试生图」再开自动
- 需要 SillyTavern 1.12+
