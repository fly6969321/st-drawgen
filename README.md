# 🎨 · DrawGen

SillyTavern 第三方生图扩展。

## 1.6.32：恢复图片点击预览

- 点击楼层内生成的图片，在独立预览窗口中查看；支持标记图片和无标记楼层末尾的图片。
- 预览当前选中的历史图片；翻页、折叠、重绘后仍可点击。
- 支持关闭按钮、点击背景、Esc 关闭，以及 Enter / 空格打开。
- 使用原生 dialog 顶层显示，避免普通主题层级遮挡；不支持该接口的旧 WebView 使用固定定位兜底。
- 只处理 DrawGen 图片，不拦截其他图片或将触摸滚动误当点击。

### 手动安装修复包

1. 备份当前插件目录中的 `index.js`、`style.css`、`manifest.json`。
2. 将修复包中的这三个同名文件覆盖到**现有 st-drawgen 插件目录**，不要创建重复的嵌套目录。
3. 完整刷新酒馆页面；如仍显示旧版本，清除该站点的缓存后重新载入。
4. 确认插件版本为 `1.6.32`，展开已有图片后点击图片本身，检查能否放大预览。

此修复不更改聊天图片数据或生图 API 配置，不需要重新生成已有图片。

### 开发与回归测试

使用 Node.js 22.22.2+（22.x）或 24.15.0+（24.x）或 26+（本次验证环境为 Node.js 24.18.0）：

```sh
npm ci
npm run check
npm test
```

运行时仍只需要 manifest 指定的 `index.js` 和 `style.css`；npm 依赖仅用于开发测试。

测试使用模拟 SillyTavern 上下文，覆盖两种图片位置、历史翻页、折叠/重绘、多个图片槽、键盘操作、原生 dialog 分支/旧 WebView 兜底、加载错误与清理。另用真实浏览器的本地模拟聊天页检查了预览打开/关闭、历史横图，以及 390 × 844 窄屏边界。

尚未在用户实际酒馆主题、移动端 WebView 或真实生图接口上端到端验证。
