# 🎨 · DrawGen

SillyTavern 第三方生图扩展。

## 1.8.0：落盘与标记识别稳定性 + 提取提速

按酒馆自身机制排查了一轮，修掉的都是能复现的显性问题。

**注入「落盘」不稳定** —— 病根是酒馆的 swipe 机制。每条回复的 `extra` 另存一份在 `msg.swipe_info[swipe_id].extra` 里，切 swipe 时酒馆会用它整个覆盖 `msg.extra`。插件把注入记录（`sdg_desc`/`sdg_tag`）和图库（`sdg_gal`）都写在 `msg.extra`，却从不回写 `swipe_info`，所以左右滑走再滑回来，这些数据被整体抹掉：正文里的 `image###…###` 还在，但记录没了（重注入会说「这层没有提取记录」）、图也不显示了。现在写 extra 的同时同步 `swipe_info`，并在 `MESSAGE_SWIPED` 时反向补齐（图库按 swipe 合并，不会挤掉在别条回复里生的图）。

同时：`saveChat()` 之前是裸调不等结果、失败被空 catch 吞掉，连续两次调用还可能互相覆盖；现在统一走一个落盘函数，同一帧内多次改动只写一次、await 结果、失败明确提示。生图期间切回复不再把图归到新那条（认发起时那条），删楼后不再往已经移出聊天的孤儿楼里写图。

**标记 `image###…###` 识别不稳定** —— 模型写法稍有偏差就整楼认不出来。实测：少写一个井号（`image##…##`）和全角井号（`image＃＃＃…＃＃＃`）**完全识别不到**；多写井号会把 `#` 带进提示词并在正文留残字；漏写闭合时会把后面那个完好的标记**整个吞掉**并匹配出一个错标记。现在井号数量不限、容忍全角与大小写，漏闭合时只丢残缺那个、后面完好的照常识别。剥离（提取前去掉上一轮的生图块）同样放宽，免得旧提示词被副AI照抄。

**提取慢** —— 最大头是提取锁把生图圈在里面了：生图要几十秒，这期间下一楼的提取一直干等（还每 300ms 空转一次）。现在生图在锁外跑，提取做完立刻解锁；顺带修了生图失败会误触发「提取重试」白烧一次提取。另外提取请求加了输出封顶（`max_tokens`），送给副AI的正文上限从 9000 字降到 4000 字（生图只画此刻这一个画面，取的仍是最新的末尾片段）。提取加了看门狗：中转站吞连接时不会再出现「提取按钮永久变灰、自动提取静默不动」——以前只能点「停止」救回来。

**计费** —— chat 通道失败后原来**不看原因**就再打一次 `/images/generations`：被限流（429）时立刻二连击、鉴权失败（401）白打两次、而站点已返回 200 但解析不出图的情况更是同一张图扣两回。现在只在「这个站的 chat 通道根本不通」时才兜底（404/405/501/400、网络层错误）。锁脸走编辑接口的四种形状轮试同理，站点返回 200 就不再试下一种。

**输入框偷偷退回老默认** —— 「延迟」清空或填 0 会存成 **1800**（直接废掉上一轮的提速），「图片宽度」清空会存成 **60**（图永久变窄）。现在都退回当前默认值，并把真正生效的值回显到框里。提取「超时」默认从 0（不限，会锁死）改成 180 秒，老配置里的 0 一次性抬上来。

**其它** —— 图片 URL 下载过去既无超时也无中止信号，CDN 卡住就整条生图永久悬挂、那一槽一直转圈且点「停止」掐不断；现在带上超时和信号。「停止」改成能掐断**并发**的生图（原来是单例控制器，后发的会覆盖先发的，先发那个就再也停不掉，而且不管有没有在跑都报「已打断」）。分层提取时模型说「沿用」但其实没有旧值可沿用，那层会被抹空，现在会在状态条里说明是哪几层。

**面板** —— 手机端整体变矮 60px（上下边缘各收 30px）。修「延迟」和「图片宽度」两个输入框不在一条线上：长标签在窄屏换成两行把左边输入框顶了下去，现在格子统一底边对齐，标签换几行都齐平。

回归测试 72 项（`npm test`）。

## 1.7.1：面板更紧凑 + 自动提取提速

- 面板上下内边距、分区间距和勾选行间距整体压缩（手机一屏多看几行）。
- 自动提取的固定等待从 1800ms 降到 800ms（消息在事件回调时已落库，不必傻等）；老配置没自定义过这个延迟的自动迁到 800ms，自己改过的不动；面板里仍可自行调整，下限 100ms。
- 提取请求发送前会剥掉本插件自己注入的生图块（`image###…###` / 模板块 / `<draw>…</draw>`，那是上一轮产物不是剧情）和内嵌 base64 图片，少烧 prefill、首字更快；剧情文字和外链图片不受影响。
- 上一轮提取还在跑时的忙等轮询从 1200ms 缩到 300ms。
- 修复 v1.7.0 的一个播种问题：内置**提取**站点档案因结构错误实际没播上（新鲜安装会退成一个空站点），现在 13 个生图站 + 1 个提取站都会正确内置。

## 1.7.0：与 Tavo 生图工坊 v1.18.x 对齐

- 首次安装自动播种内置站点档案（生图 13 个 + 提取 1 个，地址 / 模型 / 尺寸 / 画质随档案带好，**Key 为占位符 `sk-在此填入你的Key`，需自己填中转站密钥后才能生图**）；只播一次，已有站点的老用户不受影响，之后完全自己增删改。
- 生图设置新增「画质 quality」下拉（GPT 2.5 系 low/medium/high/xhigh/max，Grok low/medium/auto，留空不发送），选择随站点档案保存。
- 生图统一先走 `chat/completions`，失败自动退 `images/generations`；地址直指 images 接口时直连；站点只认 `response_format=url`（如 fate）被 400 拒时自动改发 url 重试一次。
- 尺寸里的全角 `×` 发送前自动归一化成半角 `x`，避免部分站点秒拒。
- 生图超时（默认 300 秒，可调）与「停止」按钮真正能掐断请求；超时 / 取消后不自动补发，以免重复扣费。
- 失败提示直接给 HTTP 状态码（429 / 402 / 401 等）和站点返回的原话，不再倒一大坨英文。
- 画风行新增 ⬆ / ⬇ 按钮：导出画风 JSON（只含画风，不含 API 与密钥）；导入兼容画风包与预设包——模板拆成前缀 / 后缀两段（构图脚手架进前缀、风格正文进后缀，分层生图时前缀占位符自动填当楼六层值），提取规则 / 系统提示 / 角色锚点按名字归并，旧五标签合同导入时机械升级为六标签。
- 楼层挂图仍用酒馆版自己的 `image###…###` 标记原位替换方式，与 Tavo 端的消息附件挂载互不相干；其余生图 / 提取逻辑两端通用。

## 1.6.34：简洁的手机图片预览

- 点开时先完整显示图片，按屏幕等比缩小，不再默认放大到 100%。小尺寸图片不会自动放大。
- 始终加载当前选中的原图；放大和缩小都保持原图长宽比例，不拉伸、不改图片数据或分辨率。
- 手机双指捏合放大、缩小；放大后可单指拖动查看。手势只影响预览图片，不缩放整个酒馆页面。
- 界面只保留图片和右上角的小关闭叉，不显示工具栏、比例、切换按钮或加减按钮，也不添加电脑滚轮缩放。
- 每次重新打开都恢复完整图片视图；保留 Esc/背景关闭、焦点恢复、历史图片选择和旧 WebView 弹窗兜底。

### 更新

通过 Git 安装的用户可在酒馆扩展管理里更新本插件，随后完整刷新页面，确认版本为 `1.6.34`。

手动安装：先备份插件目录中的 `index.js`、`style.css`、`manifest.json`，再用新版本的三个同名文件覆盖。不要创建重复的嵌套目录，无需重新生成已有图片。

此修复不更改聊天图片数据或生图 API 配置，也不会把低分辨率图片变成高分辨率图片。

### 开发与回归测试

Node.js 版本要求以 `package.json` 的 `engines` 为准：

```sh
npm ci
npm run check
npm test
```

运行时仍只需要 manifest 指定的 `index.js` 和 `style.css`；npm 依赖仅用于开发测试。

自动化测试覆盖图片打开、历史选择、默认适屏、等比缩放、双指中点、单指拖动、手势取消、缩放后关闭/重开、键盘焦点及清理；并验证没有增加滚轮缩放或额外按钮。触摸手势通过模拟 PointerEvent 检查。

另在真实浏览器的 390 × 844 窄屏视口检查初始完整显示、图片比例和小关闭叉。尚未在用户实际酒馆主题或手机触屏上实测。
